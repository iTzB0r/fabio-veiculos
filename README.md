# Fábio Veículos: site de loja de veículos

Site de uma loja de veículos, feito em HTML, CSS e JavaScript, em um único arquivo (`index.html`) mais as imagens.

## Recursos

- Galeria de veículos.
- Simulador com botão "Consultar condições".
- Layout para celular e computador.

## Como ver

Abra o `index.html` no navegador.

## Observação

A marca, os textos e as imagens pertencem ao respectivo negócio.
